# Security contact

Send security reports to both `ted@turbos.finance` and `bruce@turbos.finance`.
The initial acknowledgement target is within four business hours.

Include affected package/version, reproduction steps, impact and transaction digests.
Do not send private keys, seed phrases or passwords. Report privately and use
non-destructive reproduction steps.

Policy: https://turbos.finance/security.html
Machine-readable contact: https://turbos.finance/.well-known/security.txt
